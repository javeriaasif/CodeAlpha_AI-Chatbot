## 🌟 Key Features (Advanced Level)

### 1. 🧠 NLP Engine (Natural Language Processing)
- Lowercase conversion
- Special character removal
- Keyword based intent matching
- No more exact match needed

### 2. 💾 Memory System
- Remembers user name
- Example: \`my name is Javeria\` -> Bot will remember

### 3. 📚 Self-Learning Bot
- Teach bot new things at runtime
- Syntax: \`learn: question | answer\`
